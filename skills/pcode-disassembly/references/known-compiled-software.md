# Known compiled-BASIC software

This catalog preserves known **component-level** findings: games, loaders, editors, utilities, compiler applications, and explicitly separated modern or primary-source cases. It is not a claim that every listed game is wholly compiled BASIC, nor a detector allowlist based on names.

**Evidence.** Binary-backed rows rely on runtime/layout or component analysis. A recognized runtime alone does not prove application execution, historical producer, complete decoding, or whole-game compilation. BLITZ is a presentation umbrella including Austro; technical distinctions and producer uncertainty remain. Real software is not excluded merely because it later served as a validation specimen.

**Metadata.** Earlier audited company/year fields are reported metadata, not newly verified bibliography. Archive-only attributions, copyright text, release dates, and conflicting version labels are distinguished. An archive date or filename year is not a verified release year. Unknown means unknown. Duplicate media are merged only at the supported software/component scope; stated edition distinctions remain.

**Encoding.** G64 is a container, not a disk encoding. D64 does not preserve physical encoding. Only inspected encoding evidence is named below; filename hints are not proof. Standard Commodore GCR with a nonstandard boot/directory layout is not a new bit codec.

**Inventory:** 162 rows: 152 binary-supported software/component entries, 5 compiler applications, 1 modern local derivative, and 4 primary-source-only entries. The 21 review candidates are separate and unaccepted.

## Partial-storage additions — November 2026

Nine newly identified software/package rows comprise five game titles with partial compiled components (St. Pauli, W.A.R., Nibelungen, Vampire's Empire, Star Trekking II) and four utilities/companions (Top Secret Stuff, Apollo, Gemini, 3-in-1 Football Standings/League Leaders). All nine were associated through **standard GCR** directory/loader paths and sector links, not a newly decoded alternative bit format. Complete file recovery was not an admission prerequisite.

Silent Service was already known to use DTL. Strict RapidLok record decoding adds **protected-carrier/encoding evidence**, not a new title. Short shared helpers, stock-ROM code, filename guesses, and co-resident runtime libraries alone were not admitted as application findings.

- **Synthetic compiler probes, smoke/omnibus programs, and Star Salvager / INTEGERGAME:** Compiler-generated tests are not catalog software releases.

- **Austro-Speed compiler:** Application entry not reached; loader bytes do not establish compiler application representation.
- **INPUT64 Speedcompiler compiler:** Stored output-runtime template found, but application VM execution not established.
- **BASIC-BOSS compiler:** Shared native helper/template alone does not identify compiled BASIC application.
- **Standalone RTL-64/runtime libraries:** Runtime-only compiler support library is not a separate compiled BASIC application.
- **Bits, Pieces and Clues gameplay:** Only co-resident Word Writer editor established; actual editor catalogued instead.
- **Chess Champion gameplay:** Only co-resident PEG-OUT cribbage established; merged into Peg Out.

- **Snooper Troops titles:** Substantial interpreted BASIC; no reviewed compiler evidence.
- **Ziggurat:** Earlier claim unresolved and later native/loader findings exclude it from current PETSpeed pursuit; not a universal absence proof.
- **Pirates!:** Compiled-BASIC claim contradicted by cited BASIC plus assembly correction.
- **Twinner:** BASIC authorship and shared compiler author do not prove Diabolo compilation.
- **Quod Init Exit II final release:** Development BASIC-BOSS history does not establish final-release implementation.

## Coverage limits

The earlier census primarily covered standard GCR/DOS files. The bounded follow-up checked 5,944 supplied G64 images with supported RapidLok v1-compatible and later-Vorpal record profiles: 51,702 accepted record observations, not independent software objects. A separate gap-directed pass freshly verified 440,156 unlinked standard-GCR observations across 1,189 images. Existing narrowly decoded specimens were checked separately; overlaps are not additive coverage.

This does not exhaust alternative encodings, protection revisions, encrypted/packed contents, circular-boundary custom records, tapes, cartridges, or unknown compiler variants. A negative scan is not proof of no compiled BASIC. Compiler applications require application evidence rather than an included output-runtime template. Synthetic compiler probes and fresh test recompilations are excluded from the release inventory.
