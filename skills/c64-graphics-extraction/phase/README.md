# Compare two registered animation loops

Use `python3 -B compare_animation.py FIRST/manifest.json SECOND/manifest.json --reflect-x` to ask whether the two exports show exactly the same timed native loop.  Python 3.10 or newer; no image library required.  The callable is `compare(first, second, reflect_x=True)`.  Omit the option for identity only.  The command prints JSON; exit codes are 0 for a match, 1 for a difference, and 2 when comparison is not supported by the inputs.

Supply two completed `c64-animation-export-v1` manifests from the `c64-animation-v1` exporter.  The caller is responsible for registration: local `(0,0)` in each full plane must denote the intended common canvas corner after removing translation.  Different source-world origins are fine.  There is no per-frame recentering, crop alignment, sprite identification, or palette remapping.  Reflection, when requested, maps the second plane's `x` to `width-1-x` on every row.  Time always runs forward.

Only the declared half-open `source_loop` intervals are compared.  Physical loop lengths must agree, not merely animation speed after normalization.  A phase `p` means `first(t) == transformed_second(t+p)` modulo the loop duration; zero is the start of each respective source loop, not the movie intro.  Times are exact rational seconds, encoded as strings.  Every matching offset and tested orientation is returned.  `[]` means no offset works; `"any"` means even a fractional shift is indistinguishable because the loop is constant.  Unknown source loops, missing rational clocks, or incompatible native canvas dimensions yield `not_comparable`.  Native plane lengths, their hashes, index values, and the exported per-frame durations are checked.  This does not attest source provenance, obscured layers, or historical playback.

The comparison treats completed index planes (including transparent 255 and opaque black 0) as run labels, merges equal neighbors including across the seam, and compares cyclic sequences of `(plane, exact duration)` tokens.  In a nonconstant loop, any match must align every visible change.  Searching those changes finds even offsets inside a *declared* frame without enumerating fields, centiseconds, or common-denominator subdivisions.

Run `python3 -B -m unittest discover -s tests -p test_compare_animation.py -v` from this directory.  The original indicator fixture has three colored lamps and a black foot.  Its occupancy mask never changes, even under reflection; only the native colors and exact holds reveal whether its phases agree.
